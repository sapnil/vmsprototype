# **App Name**: VendorLink

## Core Features:

- GST Autofill: Each PAN can have multiple site. Each site is identified with a unique GST number. Automatically fetch and prefill vendor registration details (except trade name) by integrating with the GST API on entering GST number. This will simplify data entry for vendors, minimize data input errors, and expedite the empanelment process. The user interface acts as a tool to call external API, display data to end-users and allow to submit vendor's data.
- Contact & Identity Details: Capture vendor contact information, addresses, and key personnel details.
- Bank Details Capture: Securely capture bank details of the vendor for payment processing.
- Business Attributes: Collect business-related attributes, including nature of business, nature of expense, and payment frequency.
- Reference and Background Checks: Provide a section to input references and document background checks performed on the vendor.
- Document Upload: Enable vendors to upload required documents such as registration certificates, PAN cards, and address proofs.
- Submission and Approval: Allow vendors to submit the completed empanelment form and facilitate an approval workflow on the admin side.

## Style Guidelines:

- Primary color: Deep sky blue (#42A5F5), evoking trust and reliability in a professional context.
- Background color: Light gray (#F5F5F5), providing a clean and neutral backdrop for content.
- Accent color: Forest green (#4CAF50), used for action confirmations and highlights to signify approval and security.
- Font: 'Inter', a grotesque-style sans-serif providing a modern and neutral look suitable for headlines or body text.
- Use a consistent set of simple, outline-style icons for form elements and navigation to provide clarity.
- Employ a clear, step-by-step form layout to guide users through the empanelment process. Use field groupings.
- Use subtle animations for loading states and form validation to enhance user experience.
